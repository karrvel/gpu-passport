GPU Passport

Proof of where an AI chip is.

A signed answer can only travel so fast. We time it, and the speed of light puts a hard ceiling on how far away the GPU can be.

    Three steps. One law of physics.

    An anchor we trust sits in Tashkent. The GPU server runs a small agent. Every check takes a fraction of a second.

    1

    Challenge

    The anchor sends a fresh random number that nobody could have guessed in advance.

    2

    Sign

    The agent on the GPU server signs it with a key tied to that GPU and returns the signature.

    3

    Bound

    The round-trip time caps the distance. Light in fiber covers about 200 km per millisecond, so the reply could not have come from farther.

    1 ms ≈ at most 100 km

    Honest limits.

    Upper bounds only

    Timing proves a chip is no farther than X. It cannot prove it is exactly here.

    Distance, not borders

    One checker proves distance, not a border. Shymkent, Kazakhstan is about 120 km from Tashkent. Several anchors in different cities narrow it to inside the country.

    Software keys can be copied

    Until the key is bound to hardware attestation, a copied key could answer from another machine. That is the next milestone.

    Hops only add distance

    Tunnels and relays can only make a host look farther, never closer. The relay test above was caught exactly that way.
